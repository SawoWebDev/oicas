1. Sign in

  1. Open OICAS in your browser (e.g. http://<server>:8086).
  2. Live: enter your ERP (erp.sawo.com) username/email and password and press Log in with Odoo. Odoo checks your password; OICAS never stores it.
    Demo: use admin, manager, counter or viewer with password demo.
  3. Your role (viewer, counter, manager or admin) comes from your Odoo groups. See Roles & permissions.

2. Find your way around

Left sidebarAll modules, grouped as Overview, Inventory, Analysis and Governance. You only see what your role allows. The search box at the top finds an item by RM code or description.
Top rightLIVE/DEMO badge · Odoo date/time: when the last Odoo snapshot was taken; red means stale (click it to open Synchronization History) · today's date · page buttons.
BannersYellow: demo mode. Red: Odoo data is older than allowed (default 24 h), so Odoo figures aren't current. Green or red message bars: the result of your last action.
TablesClick a column header to sort (click again to reverse). Use the filter bar and Apply; Reset clears it. Click the first column (e.g. the RM code) to open the record. Excel / PDF export exactly what's shown.
HelpThe red ? button (bottom right) or F1 opens help for the page you're on. Help Center in the sidebar lists every topic.
Bottom leftYour name and role; the arrow icon logs you out.

3. First-time setup (administrator, live)

  1. System Configuration → Imports → Migrate legacy workbooks: loads the Excel history (items, ABC/AMC, all past counts). Run it once.
  2. Synchronization History → Sync Odoo now: loads products, locations and stock from Odoo using your ERP login.
  3. System Configuration → Odoo locations: mark each Odoo location as WAREHOUSE, PRODUCTION or IGNORE, then sync again.
  4. Data Import: add items that aren't in Odoo yet, with their book balances.
  5. Data Quality: work through open issues such as missing plant locations or unknown codes.

4. Daily use

Counter: Cycle Count Planning → plan → Start counting (or upload the filled count sheet) → Submit. Physical Counting keeps the uploaded COUNTED LIST workbooks.
Manager: Planning → create plan → (counters count) → finalize sessions → review discrepancies in Odoo Reconciliation.
Everyone: Dashboard and Reports.
