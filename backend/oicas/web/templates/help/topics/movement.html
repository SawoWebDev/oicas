The classification matrix (the old CLASS sheet) turns each ABC category into an action, a movement classification and a count interval.

CategoryDeclared typeActionClassificationCount every
AA, AB, BAMTS{{ pill('CLOSE CONTROL') }}{{ pill('Fast Moving') }}30 days
BB, CA, ACMTS{{ pill('REGULAR REVIEW') }}{{ pill('Medium Moving') }}90 days
BC, CB, CCMTO{{ pill('INFREQUENT REVIEW') }}{{ pill('Slow Moving') }}180 days
any, with no demand in any month(from category)(from category){{ pill('Non Moving') }}(from category)

MTS = make to stock, MTO = make to order. The matrix can be changed (with a new rule-set version) in System Configuration.

On the screen

Counts per class, then a list grouped Fast → Medium → Slow → Non Moving: code, description, category, months with demand, total demand, AMC, action, interval, priority (1 = close control … 3 = infrequent), next count and schedule status. Filters: class, section, family, plant.

Example
10RM12-079 has no demand in Sep–Jul but category AC → classification Non Moving (no demand overrides the class), action REGULAR REVIEW, interval 90 days.
