Loading from Odoo (erp.sawo.com) is always read-only: OICAS reads products, locations, stock and manufacturing demand, and never creates, changes or deletes anything in Odoo.

What a sync reads

Odoo dataBecomes in OICAS
Products (Internal Reference, name, unit of measure, active)Items: code, description, UoM, Odoo product id
Internal stock locationsLocations, mapped by you to WAREHOUSE / PRODUCTION / IGNORE
On-hand quantities (stock quants)A dated, unchangeable snapshot: stock per item for WAREHOUSE and PRODUCTION
Manufacturing-order component demand (via Sync demand on AMC Analysis)A demand batch per month and item

How to sync

  1. Open Synchronization History (manager).
  2. Press Sync Odoo now. In live mode, OICAS reads Odoo with your ERP login and your Odoo access rights. If the server was restarted since you logged in, enter your ERP password once; it's kept only in memory for your session.
  3. The message shows the result: snapshot #, number of products and quants. The new run appears in the table.
  4. The first time: map the locations in System Configuration → Odoo locations, then sync again.

The page

  • Latest Odoo snapshot: number, time and age; red when older than the limit (default 24 h).
  • Last successful sync and Connection (live or fake, Odoo URL).
  • History: every sync and import with kind, status ({{ pill('success') }} / {{ pill('failed') }}), times, records, quants, snapshot, quants in unmapped locations and any error.
If Odoo is down, the sync fails safely: nothing is changed, the last good snapshot stays in use, and every page shows a red stale banner so nobody mistakes old figures for current ones.
Example
Monday 07:30: the manager presses Sync Odoo now → snapshot #42 with 2,053 balances. Counts finalized today are compared with #42. Counts finalized last week stay compared with the snapshot they were finalized against, so history doesn't change.

Items Odoo doesn't have can be added with Data Import.
