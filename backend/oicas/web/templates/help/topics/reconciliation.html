The comparison of what was physically counted with what the system says, per location: Variance = Physical − Odoo. A negative variance (red) means less stock was found than Odoo shows.

How a result is calculated

  1. All active entries of the item on that count date are added up per location (Warehouse, Production).
  2. The system balance is taken from the Odoo snapshot linked to the session. If Odoo has no balance for the item (e.g. it isn't in Odoo), the latest imported book balance dated on or before the count date is used instead.
  3. Variance per location = physical − system. A location that wasn't counted shows “–” and isn't compared.
  4. Status: {{ pill('accurate') }} all compared locations equal (within the tolerance, default 0) · {{ pill('discrepancy') }} at least one differs · {{ pill('odoo_missing') }} counted but no system balance to compare.

The list (Odoo Reconciliation)

Columns: count date, code, description, class at count, physical / Odoo / variance for WH and PROD, absolute variance, status, review, counted by, snapshot. Filters: date range, code, class, status. The summary shows reconciled counts, number with discrepancy, rate, and net and absolute variance (quantities, not money).

Review a discrepancy (open a row)

Add noteRecords a comment. The status doesn't change.
InvestigatingMarks it as being checked; an assignee is optional.
Request recountAdds the item to the Recount requests plan. Then use Start recount session: the recount replaces that day's earlier figures for the item, which stay in history.
ResolveCloses it. An explanation is required (e.g. "Odoo adjusted by stock controller", "issued to production, not yet posted").
ReopenRe-opens a resolved discrepancy.

The page also shows where the system balance came from (Odoo snapshot, legacy Excel or imported book balance), every entry behind the figure, and the full note timeline.

OICAS never changes Odoo. If stock must be adjusted, the authorised person does it in Odoo. After the next sync and recount, the item shows as accurate.
Example
1SH03-001 Frame PM, 2026-10-20: Warehouse physical 2,400, Odoo 2,403 → −3; Production not counted (“–”), Odoo 4 → not compared. The manager requests a recount and Christine counts 2,403 → the new result is accurate and replaces the old one, which stays in history.
