Every count entry ever recorded, in any session status. It replaces scrolling through the COUNTED LIST sheet.

Columns

Date · Session · Status (draft / submitted / finalized / cancelled) · Counted by · RM Code · Description · Location · Slot · Round · Qty · UoM · Entry (active, or superseded when corrected or recounted) · Correction reason · Remarks.

Filters

From / To (default: last 90 days), search code, session status, counted by. The summary shows the number of entries, active entries, sessions and items.

Example
To see everything Giniemark counted in September: From 2026-09-01, To 2026-09-30, Counted by "Giniemark" → Apply → Excel.

Nothing is ever deleted: a correction adds a new entry and marks the old one superseded, with the reason and who did it.
