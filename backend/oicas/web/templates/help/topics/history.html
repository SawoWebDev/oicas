Every count line of the COUNTED LIST workbook uploaded on Physical Counting. By default the latest upload is shown; pick an older one in the Counted list upload filter.

Columns

Date (DATE COUNTED) · Counted by (COUNTED BY) · RM Code · Description · Location · Qty · UoM (Odoo) · Remarks.

  • Location is the COUNTED LIST column the quantity is in: WH-1 … WH-4 or PROD-1 … PROD-4. A LIST line with quantities in two columns shows as two rows.
  • UoM is the product's unit of measure in Odoo (refreshed on every Odoo sync). It is blank when the code is not an Odoo product.
  • Remarks is the REMARKS column of the COUNTED LIST line.

A blank count cell is not a count; 0 is a counted zero.

Filters

Counted list upload, From / To, search code or description, location, counted by. The summary shows count lines, items, counted dates and codes with no Odoo UoM.

Example
To see everything Giniemark counted in WH-3 in September: From 2026-09-01, To 2026-09-30, Location WH-3, Counted by "Giniemark" → Apply → Excel.
