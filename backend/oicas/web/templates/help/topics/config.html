Administrator settings, in five tabs. Every change is validated and recorded in the Audit Trail.

Rule sets

The calculation rules, versioned. Saving creates a new version with an effective from date and never edits an old one, so past results stay reproducible.

ABC thresholdsQty A if cumulative < 80 %, C if ≥ 95 %; Freq A if > 80 %, C if ≤ 50 %
ABC orderingRank by total demand (normal), or keep input order (only for replaying the old Excel)
AMC methodAverage of months with demand (as Excel), or total ÷ months in period
Abs. toleranceA variance at or below this quantity counts as accurate (default 0)
Uncounted locationNot counted (no variance), or treat as 0 (the old Excel behaviour)
Missing Odoo balanceMissing (no variance), or treat as 0 (the old Excel behaviour)
Never-counted itemsDue now, or unscheduled
Upcoming windowDays ahead counted as "upcoming" (default 7)
Classification matrixCategory → declared type, action, classification, interval days (the CLASS sheet)

Odoo locations

Map each internal Odoo location to WAREHOUSE (compared with "Odoo WH"), PRODUCTION (compared with "Odoo Pre-Prod") or IGNORE. Unmapped locations are excluded and flagged. A change applies from the next sync.

Settings

Lists (material sections, ABC families, plant locations, count slots), the Odoo-group → role map, the default role, the staleness limit in hours, whether cancelled MO moves count as demand, and snapshot retention days.

Users & roles

Users appear after their first login. Change the role, lock it (so Odoo groups don't override it) or deactivate a user (this signs them out). Active sessions shows who is signed in, with Revoke all.

Imports

The one-time legacy workbook migration (each file can be imported only once), a link to Data Import, and the import history.
