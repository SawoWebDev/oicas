Decide what to count next and who counts it. The schedule is calculated automatically: next count = last count date + interval (30, 90 or 180 days from the item's classification).

Schedule statuses

{{ pill('overdue') }}Next count date has passed.
{{ pill('due_today') }}Due today, including items never counted (they're due as soon as an analysis is approved).
{{ pill('upcoming') }}Due within the next 7 days (adjustable in the rule set).
{{ pill('scheduled') }}Due later.
{{ pill('unscheduled') }}No interval (no classification yet).

Order: the earliest due date comes first, then by action (CLOSE CONTROL before REGULAR before INFREQUENT), then never-counted items.

Create a count plan

  1. On Cycle Count Planning, fill New count plan: name, plan date, due date.
  2. Choose Items: All overdue / due today, Overdue, due and upcoming, or Only the items ticked. To tick items, filter the schedule below and use the checkboxes.
  3. Optional: Plant location to limit the plan to one area, and Assign to a counter.
  4. Press Create plan. The plan page opens.

Plan page

  • Tiles: items, counted, remaining, plan and due dates.
  • Count sheet (Excel): the fillable sheet with blank WH-1…4 and PROD-1…4 columns for counters, uploaded later on Physical Counting.
  • Printable PDF: a paper count sheet.
  • Start counting: opens a count session linked to this plan.
  • Tick items and use Assign ticked to give them to a person; Close plan when done.
  • Item status changes from pending to counted automatically when a session that contains the item is finalized.
Example
Monday: filter the schedule Schedule = overdue, Plant location = 3 → 120 items. Create plan "Week 43 – Plant 3" with "Only the items ticked" (select all), assign it to Christine A, and download the count sheet. She fills it in during the week and uploads it.
A Recount requests plan is created automatically when a manager requests a recount from the reconciliation page.
