Login

"Invalid Odoo login or password": use exactly what you use on erp.sawo.com. After 5 wrong tries, wait 15 minutes.
"Odoo is unreachable": erp.sawo.com can't be reached from the OICAS server. Try again later or tell IT.
"Your Odoo groups don't grant access": ask an administrator to give you a role in System Configuration → Users.

Counting

I typed a wrong quantity. Draft: Remove and add it again. Submitted: ask a manager to Correct it with a reason.
"Unknown item code": check for typos. If the item isn't in Odoo, a manager adds it in Data Import → Items.
Finalize asks about stale Odoo data: press Sync Odoo now first, or tick the box if you knowingly accept older data.
Production shows “–”: production wasn't counted, so it isn't compared. Enter 0 only if you counted and found nothing.

Numbers look different from the old Excel

  • Excel counted duplicate masterlist rows; OICAS counts each item once.
  • Excel treated an uncounted location or a blank Odoo value as 0, which created false discrepancies. OICAS doesn't (adjustable in the rule set).
  • The RM sheet in Excel had a formula error (total only up to row 678) and wasn't sorted; OICAS ranks correctly.

Odoo & imports

Sync asks for my password: the server was restarted since you logged in. Enter your ERP password once.
An Odoo location's stock is missing: map the location (System Configuration → Odoo locations) and sync again.
Import rejected: open the result. Every error has a row number; fix the rows and upload again. Nothing was saved.
Item now has an Odoo code: item page → Change item code.

Other

Can OICAS change stock in Odoo? No. It's read-only by design.
Is anything ever deleted? No. Counts, corrections, snapshots, analysis runs and settings keep their history.
