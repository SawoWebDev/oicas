16 ready-made reports. Each has filters, sortable columns, a summary line, and Excel and PDF buttons that export exactly what's on screen, with the SAWO logo, title, period, filters and data versions.

Custom report (16)

Type field keys separated by commas in Fields, e.g. code,description,plant_location,classification,next_due,disc_wh. Choose Sort by and Group by (group totals appear in the summary). The available keys are listed under the table.

Example
Monthly management pack: report 6 (PDF) + report 7 for the month (Excel) + report 5 filtered "Review status = open" (Excel).
Every export is logged with a fingerprint (SHA-256), so a file can be traced back to the exact data it came from.
