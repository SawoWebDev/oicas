Physical Counting keeps every uploaded copy of the COUNTED LIST workbook. Each upload is a session: you can open it to look through its sheets exactly as Excel shows them, download the original file again, or delete it.

Upload a workbook

  1. Choose the Excel file (.xlsx, up to 30 MB), e.g. COUNTED LIST.xlsx.
  2. Check Uploaded by. It starts with your name; change it if you are uploading for someone else.
  3. Press Upload. After a few seconds the new session opens.

The session list

Each row shows the session number, the date and time of the upload, who uploaded it and the actions:

  • Details opens the workbook in a large window, on the sheet Excel opens on (LIST). The sheet tabs (LIST, ODOO inv, DATA) sit above the grid. The header row and the DATE COUNTED, RM CODE and Description columns stay in view while you scroll, as in Excel. Search finds a code or description in the current sheet. Long sheets are shown 200 rows per page.
  • Export (or Export Excel in the window) downloads the file exactly as it was uploaded, formulas included.
  • Delete removes the session and its file. You are asked to confirm, and it can't be undone.

What you see

  • Dates, counts (305.00) and colours are shown as Excel displays them. Values are the ones Excel last calculated and saved, e.g. the Description looked up from DATA and the TOTAL COUNT sums.
  • Rows hidden by the Excel filter stay hidden. If the file was saved with LIST filtered to one date, you see only that date's rows; the footer says how many rows are hidden and Show them shows all of them.
  • The upload is for viewing only: its counts are not added to Reconciliation, Count History or the Annual inventory.

Counting from a plan

Counts that should be reconciled against Odoo still go through a count plan: on Cycle Count Planning → plan, use Start counting to type counts, or download Count sheet (Excel), fill it in and use Upload the filled count sheet on the same page. Those sessions are submitted and finalized on their own session page, and their results appear in Reconciliation. For many dates or counters in one file, use Data Import → Count lines.

Who can do what

Counters and above can view, export and upload. Deleting an upload needs the manager role or higher. Uploads, downloads and deletions are recorded in the Audit Trail.
