ABC familyGroup within which ABC is calculated (RAW MAT, BOX, Metal Stamping, Pre-Assy, Stone, T&D, PIM, Control Unit, Wood, SF Wood, Excluded list).
ActionHow closely an item is controlled: CLOSE CONTROL, REGULAR REVIEW, INFREQUENT REVIEW.
AMCAverage Monthly Consumption.
Analysis runOne calculation of AMC/ABC/classification for a period: draft, approved or superseded.
Book balanceImported expected stock for an item Odoo doesn't hold.
Bucket / locationWAREHOUSE (Odoo WH) or PRODUCTION (Odoo Pre-Prod).
CategoryTwo letters: quantity class + frequency class (AA … CC).
ClassificationFast / Medium / Slow / Non Moving.
Count entryOne counted figure: item · location · slot · round · qty.
Count planA list of items to count, with assignees.
Count sessionOne counter's counts on one date (draft → submitted → finalized).
Demand batchA loaded set of monthly demand (from Odoo or Excel).
Discrepancy / variancePhysical − Odoo per location.
FinalizeManager step that compares a session with Odoo and creates the reconciliations.
IntervalDays between counts: 30, 90 or 180.
JITJust-in-time item (remark on the masterlist).
Live / DemoReal Odoo with the primary database, or simulated Odoo with the secondary database.
MTS / MTOMake to stock / make to order (declared inventory type).
NC-codeTemporary code (NC-00001…) for an item imported without a code.
ReconciliationThe comparison result for one item on one count date.
RecountA new count that replaces that day's figures for the item (the old ones are kept).
RM codeThe item code, the same as the Odoo Internal Reference.
Rule setVersioned calculation settings (thresholds, matrix, tolerance…).
SlotWH-1…4 / PROD-1…4 column of the count sheet (sub-area or count line).
SnapshotUnchangeable copy of Odoo stock at the moment of a sync.
StaleThe latest Odoo snapshot is older than allowed (default 24 h).
Stock in monthsCounted quantity ÷ AMC.
TrackedThe item is part of the masterlist and cycle-count schedule.
“–”Unknown / not counted / not available. Never the same as 0.
