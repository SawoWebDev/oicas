AMC (Average Monthly Consumption) is how much of an item is used per month. Together with ABC it decides each item's classification and count interval. All of this is produced by an analysis run.

AMC formula

AMC = total demand of the months with recorded demand ÷ number of those months (the same as the Excel AVERAGE() of the month columns). A month with no demand record is left out; a recorded 0 counts.

Example
8RM04-341-1, Sep 2025 – Jul 2026: demand in Oct 24.64, Dec 120.96, Feb 20, Apr 0, May 192.64, Jul 387.46 (6 recorded months, total 745.7) → AMC = 745.7 ÷ 6 = 124.28. (The alternative method, total ÷ 11 months = 67.79, can be selected in the rule set.)

Stock in months = counted quantity (WH + PROD) ÷ AMC. Example: 214.882 ÷ 124.28 = 1.73 months. It's blank if the item isn't counted or the AMC is 0.

Analysis runs: calculate → review → approve

  1. Get demand: Sync demand reads manufacturing-order component demand from Odoo for a period, using your ERP login. Alternatively, upload an Excel export (here or in Data Import). Each load becomes a demand batch.
  2. Calculate: choose the demand batch, first month and number of months (e.g. 2025-09, 11) → Calculate draft run.
  3. Review: the run page lists every item whose category, classification, action, interval or AMC changed compared with the approved run.
  4. Approve (manager): the masterlist, schedule and dashboard switch to the new run. The old run is kept as superseded. Reject discards a draft.

Analysis runs table

Run #, period, source (engine = calculated by OICAS; legacy import = values taken from the old Excel), rule set version, status ({{ pill('draft') }} {{ pill('approved') }} {{ pill('superseded') }} {{ pill('rejected') }}) and Detail.

AMC report (below)

Per item: demand per month, total, months with demand, AMC, latest physical quantity, stock in months and classification. Filter by run, family, class or code.

Only an approved run is used by the rest of the system. Drafts never change the masterlist.
