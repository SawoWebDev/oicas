Counting & reconciliation

Physical WH / PRODSum of all active entries of the item, for that location, on the count date (WH-1 + WH-2 + WH-3 + WH-4).
Variance (discrepancy)Physical − Odoo, per location. Negative = less found than Odoo shows.
Has discrepancy|variance| > tolerance (default 0) in any compared location.
Absolute / net variance|WH var| + |PROD var| ; WH var + PROD var (quantities, not money).
Latest count of an itemThe reconciliation with the most recent count date.

Weekly progress (report 7)

Weeks run Monday–Sunday; the date shown is the Sunday. Week # = Excel WEEKNUM(date, 2). Total counted = items counted that week · Accurate = counted − discrepancy − not verifiable · Accuracy % = accurate ÷ verifiable · Completion % = cumulative counted ÷ # of items.

Schedule

Next count = last count date + interval days. Never counted → due on the date the analysis was approved. Overdue days = today − next count.
