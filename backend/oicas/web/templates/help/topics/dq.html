OICAS flags data problems instead of quietly fixing them, so you can decide. The red number next to Data Quality in the sidebar is the count of open issues.

Kinds of issues and what to do

KindMeaningWhat to do
unmapped locationAn Odoo location isn't mapped to WAREHOUSE / PRODUCTION; its stock is ignoredSystem Configuration → Odoo locations
not in odooA tracked item has no Odoo product (imported or not encoded yet)Encode it in Odoo, then Change item code; meanwhile import book balances
unknown item codeA code in counts or imports isn't a known item (or matched by different upper/lower case)Correct the code or import the item
duplicate product codeSeveral Odoo products share one Internal ReferenceFix in Odoo (OICAS uses the lowest product id)
product code changedThe Odoo reference of a known product changedReview, then Change item code if correct
product without codeAn Odoo product has no Internal ReferenceInformation only
negative odoo qtyOdoo on-hand quantity is below zeroCheck in Odoo
missing plant location / material section / family / uomA masterlist attribute is emptyItem page or Data Import → Items
duplicate code familyAn item is in more than one ABC familyChoose its family on the item page
duplicate count line / count line without qtyFrom imports: same item twice on a date, or a line with no quantityCheck the source file
sync failed / stale snapshotOdoo couldn't be read, or the data is oldSee Synchronization History; sync again

Actions

Per issue: Resolve, Ignore or Reopen. Issues found by a sync or by the checks close automatically once the problem is gone. Re-run masterlist checks scans all items again. Click a reference (code) to open the item.
