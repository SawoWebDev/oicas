AMC Import keeps every uploaded copy of the AMC / ABC Analysis workbook (03_AMC Sep-Jul ABC Analysis.xlsx). Each upload is a session: you can open it to look through the sheets, download the original file again, or delete it.

Upload a workbook

  1. Choose the Excel file (.xlsx, up to 30 MB).
  2. Check Uploaded by. It starts with your name; change it if you are uploading for someone else.
  3. Press Upload. Reading a large workbook takes a few seconds, then the new session opens.

The session list

Each row shows the session number, the date and time of the upload, who uploaded it and the actions:

  • Details opens the workbook in a large window. The sheet tabs along the bottom work like Excel's. Column letters, row numbers and the title row stay in view while you scroll, and on the family sheets and CONSOLIDATED the #, Code and Description columns stay in view too. Use the search box to find a code or description in the current sheet. Long sheets are shown 200 rows per page.
  • Export (or Export Excel in the window) downloads the file exactly as it was uploaded, formulas and hidden sheets included.
  • Delete removes the session and its file. You are asked to confirm, and it can't be undone.

What you see

  • Values are shown as Excel displays them: percentages such as 0.02%, whole numbers, and General numbers. They are the values Excel last calculated and saved in the file.
  • Only visible sheets are shown. Hidden sheets, such as the raw Odoo demand export and the pivot, stay in the downloaded file.
  • Rows hidden by an Excel filter are shown, so you see the whole sheet.

Who can do what

Everyone can view and export. Uploading and deleting need the manager role or higher. Uploads, downloads and deletions are recorded in the Audit Trail.
