The cycle repeats continuously. Each step feeds the next automatically, so no copy/paste between files is needed.

  1. Load from Odoo (Sync Odoo now): products, locations and on-hand stock are read from erp.sawo.com and saved as a dated snapshot.
  2. Import what Odoo doesn't have (Data Import): items without a code, book balances, demand.
  3. Check data quality (Data Quality): duplicates, unmapped locations, missing plant locations and so on.
  4. Analyse demand (AMC Analysis): calculate AMC, ABC, movement class and count interval as a draft, review the changes, then approve.
  5. See what to count (Cycle Count Planning): next count = last count + interval. Overdue items come first.
  6. Create a count plan and assign counters; print or download the count sheet.
  7. Count (Physical Counting): enter or upload the figures per location (WH-1…4, PROD-1…4).
  8. Submit (counter): entries become locked.
  9. Finalize (manager): OICAS compares physical with Odoo (or the book balance) → reconciliation.
  10. Review discrepancies (Odoo Reconciliation): investigate, request a recount, or resolve with an explanation. Stock adjustments, if needed, are done in Odoo by the authorised person.
  11. Report (Dashboard, Reports Center): progress, accuracy and discrepancies, exported to Excel or PDF.
  12. Next cycle: the next count date updates automatically, and the schedule shows the next due items.
