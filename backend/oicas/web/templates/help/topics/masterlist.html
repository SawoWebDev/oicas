One row per item, laid out exactly like the Master sheet of the Inventory Masterlist & Cycle Count tracker. It reads the latest AMC Import upload, the latest COUNTED LIST upload (Physical Counting) and the latest Odoo sync, so uploading a new file updates the page.

How to use it

  • Filter by search, movement class, action, material section, plant, Counted (yes/no) and Discrepancy (yes/no), then Apply.
  • Click a header to sort. Excel/PDF export the filtered list.
  • Click an RM code to open the item page.

Item page

  • Item: Odoo product id, UoM, last Odoo sync, section, family, plant, remark (JIT badge).
  • Classification & schedule: class, action, category, AMC, months with demand, interval, last and next count, stock in months, and the analysis run it comes from.
  • Latest reconciliation: physical vs Odoo per location, with an Open button for the review.
  • Edit OICAS-owned attributes (managers): material section, ABC family, plant location, remark, JIT, tracked. Odoo-owned fields (code, description, UoM) can only be changed in Odoo.
  • Change item code (managers): use it when an item imported without an Odoo code (e.g. NC-00001) is encoded in Odoo. All history moves to the new code.
  • Demand & ABC basis: demand per month, total, rank, cumulative %, frequency % and class per family. “–” = no demand recorded that month.
  • Count entries and Reconciliation history: every count ever made, with corrections struck through.
