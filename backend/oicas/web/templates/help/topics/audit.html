Every important action is recorded: who did it, when, from which computer (IP), and what changed (before and after). Managers and admins can view it.

What's recorded

Logins, logouts and failed logins · count sessions created, submitted, finalized or cancelled · entries added, removed or corrected (with reason) · reviews, recount requests and resolutions · plans and assignments · item attribute changes and code changes · syncs and imports · analysis runs, approvals and rejections · rule-set versions, settings, location mappings, user roles · report exports · data-quality status changes.

Filters

From / To (default: last 30 days), action contains (e.g. count.entry.correct, import, auth), user login, and entity. Up to 5,000 events are shown; export to Excel for more analysis.

Example
"Why did 1SH03-001 change on Tuesday?" → Action contains correct → the row shows manager · count.entry.correct · before=2400, after=2403, reason="recounted bin 3".
